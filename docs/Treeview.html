Treeview


Component Behavior

Collapsible tree structure for displaying hierarchical data, commonly used for navigation menus. Users can expand and collapse branches to reveal or hide nested items. The treeview supports keyboard navigation with arrow keys and maintains proper focus management throughout user interactions.


Accessibility Guidelines

The treeview follows WAI-ARIA tree pattern guidelines. The root element has role="tree" with an aria-label describing the tree's purpose. Each item has role="treeitem", and nested groups use role="group" with aria-label. Expandable items include aria-expanded and aria-owns attributes to indicate their state and associated subtree. Only one treeitem is in the tab sequence at a time (tabindex="0"), with all others set to tabindex="-1". Focus is styled with a visible outline to support keyboard navigation. Keyboard support includes Arrow keys for navigation, Right Arrow to expand/move into, Left Arrow to collapse/move out, Home/End for first/last item, and typing a character to jump to items starting with that letter.


Instructions

Copy the HTML structure of the treeview component with role="tree" on the root ul element. Each treeitem should be an anchor tag with role="treeitem". For expandable items, add aria-expanded="false" and aria-owns pointing to the subtree's id. Include the icon span with SVG for expandable items. Nested groups should use ul with role="group" and an aria-label.
