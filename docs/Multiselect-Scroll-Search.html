Multiselect Scroll Search

Provides a dropdown scrollable selection list that allows users to choose one or more items. A search window sits at the top of the list that allows people to pull up and select a particular item.

Placement

This component has 3 main elements: a label, a button, and a fieldset. Place them together in a div container.

Behavior

When you click the button, a panel expands down 200px. The panel contains a search box that will search the list, followed by a scrollable list of checkbox items. If you select only one item, it will show up in the button. If you select more than one item, the button will display a count of the number of items chosen. If you click the button again, the panel will collapse.

Accessibility Guidelines

Make sure that all items in the list are contained in a fieldset. Each input must have a unique label. The fieldset needs a legend, but since the button has a label (required), a legend that repeats the name of the list is visually annoying. So I gave it a font-size and line-height of 1px, with color = white, to make it invisible. Screen readers will know that the fieldset relates to the button.
